## The problem

A faceless YouTube creator was spending hours on every Short: researching,
writing the script, then recording the voiceover. That capped how much they
could publish. They still wanted to edit the videos themselves.

Handing the writing to AI has a catch on a channel built on facts: one wrong
stat read out loud, and viewers stop trusting it.

## What I built

An n8n workflow that turns one line in a Google Sheet into a script and a
voiceover, saved together in Drive.

1. **One line starts it.** The creator types a topic, plus any facts they
   trust, and leaves Status empty. On schedule, the workflow claims the next
   row and gives it a tag, so it's never made twice.
2. **The AI researches, then writes.** OpenAI searches trusted sources only,
   such as FIFA, BBC Sport and the clubs' own sites, then writes a 100 to 130
   word script with a strong first line. Every fact comes back with its link.
3. **Code checks the script before any voice credits are spent.** It must be
   the right length and plain spoken text, and every number in it must match
   a sourced fact. A failing script gets one rewrite. If that fails too, the
   row is marked Needs Review and nothing is spent on voice.
4. **ElevenLabs reads it out.** The MP3 is saved beside the script in a Drive
   folder for that topic, both named with the tag.
5. **The sheet and inbox catch up.** The row is marked Done with both links,
   an estimated length and the sources, and the creator gets an email.

## How it works, explained simply

Think of a small team: a researcher and a writer, a fact-checker, then a
voice actor. The AI researches and writes. Code is the fact-checker.
ElevenLabs is the voice.

- **No number without a source.** Every number in the script must appear in
  the topic, the creator's own facts, or a fact the AI found with a link. If
  not, the script is sent back.
- **Voice credits go only on approved scripts.** The checks run first, so a
  bad script never costs a voiceover.
- **Nothing gets lost.** The script is saved before the voice step. If
  ElevenLabs fails, the row says Voice Failed and the creator is emailed.
  Clearing the Status cell tries again.
- **Everything is easy to find.** Each short gets its own folder, and both
  files carry the tag, so one search finds them.
- **A crash never goes quiet.** If any step breaks, a separate error workflow
  emails the step that failed with plain advice, and marks the stuck row as
  Failed.

Five test runs took between 1 minute 35 seconds and 2 minutes 23 seconds
each, from claiming a topic to the creator's email. The Ceni short, from topic
to finished voiceover, took 1 minute 35 seconds. Three shorts finished, each
with its sources linked in the sheet.

The Ceni short also tested the safety net. Its first voiceover attempt
failed, and the email said the script was safe in Drive. Clearing the Status
cell and running it again made the voiceover.
